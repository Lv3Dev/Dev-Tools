# Dev Tools

Development overlays, NPC recording, and timing tools for plugin work.

## Features

- NPC recording panel with animation, projectile, hitsplat, and overhead-prayer logging
- Per-NPC tile highlights and animation-reset tick countdowns
- Local-only debug 1-tick pray (disabled by default)

Automatically activating prayers may violate Jagex third-party client rules and is for local debugging only.
